Prosponsive Install Guide

This guide covers installing Prosponsive and completing first-launch setup. Once you're up and running, continue to Prosponsive Basics to learn the interface.

1. Install Prosponsive

macOS

  1. Download the Prosponsive .dmg file from Prosponsive.ai.
  2. Open the .dmg and drag Prosponsive into your Applications folder.
  3. Open Prosponsive from Applications. macOS may ask you to confirm since the app was downloaded from the internet — click Open.

Windows

  1. Download the Prosponsive .exe installer from Prosponsive.ai.
  2. Bypass the security warnings. This is temporary until official Prosponsive incorporation and Microsoft developer registration.
  3. Run the installer and follow the prompts. Choose "Install for all users" if you want it available system-wide.
  4. Launch Prosponsive from the Start Menu.

Installation Overview

Prosponsive manages its own infrastructure. On first launch, it automatically starts the services it needs.

To install and run Prosponsive, you'll need:

  • A stable internet connection
  • Available disk space
  • Local administrator privileges
  • Winget (Windows) or Homebrew (macOS)

What Prosponsive Installs

Prosponsive sets up three core components:

1. Virtualized Runtime Environment

Prosponsive runs its dependencies in a containerized environment:

  • Container engine
    Prosponsive prefers Podman and will install it if neither Podman nor Docker is present. If Docker is already installed, Prosponsive will use it.
  • Database
    A PostgreSQL container is installed for persistent storage.
  • Workflow engine
    Prosponsive installs n8n, a source-available workflow engine licensed under the Sustainable Use License, used as a tool layer for your agents.

    n8n provides:

    • A visual workflow designer
    • Code-level extensibility
    • Secure credential storage
    • Thousands of templates
    • Full transparency into execution and data flow

Third-party software. Prosponsive automates the setup and integration of several independent software components including n8n, Podman or Docker Desktop, and PostgreSQL. Each of these is developed and maintained by its respective organization and is subject to its own licensing terms. It is the user's responsibility to review and comply with the applicable license agreements for each component.

2. Secure Local Networking

Your trust is a top priority. Even though all communication between Prosponsive, PostgreSQL, and n8n stays on your machine, Prosponsive enforces encrypted connections.

During installation:

  • A unique localhost SSL certificate is generated
  • You'll be prompted to trust it at the OS level
  • All certificate generation inputs are securely deleted afterward

3. LLM Provider and Model Selection

You can choose from popular cloud providers or run models locally.

Prosponsive works well with smaller, instruction-tuned models, including:

  • Local models via Ollama
  • Example: Qwen 3 (4B Instruct), if your machine has sufficient resources

If you select Ollama, Prosponsive will install it (if needed) and download your chosen model.

Installation Time

Installation typically takes 5–30 minutes, depending on:

  • Whether container tooling (Podman/Docker) needs to be installed
  • Whether optional components like Ollama and models are downloaded

2. First Launch

When you open Prosponsive for the first time, you'll see the System Health screen. This is where Prosponsive checks that its services are running and attempts to install and repair them if not healthy.

What you'll see

A grid of service tiles showing health status. Hover over each to understand its purpose more. The services are checked, and repaired, in dependency order to ensure a working Prosponsive user experience when complete.

Each tile shows a green checkmark when healthy. If a service shows an error, click the Refresh button — Prosponsive will attempt to start it automatically.

Choose your AI provider

Once services are healthy, Prosponsive asks you to select an AI provider. Pick the one you have access to:

  • Ollama — Fully local, no API key needed. Requires Ollama installed with a model pulled.
  • Anthropic — Claude models. Requires an API key.
  • OpenAI — GPT models. Requires an API key.
  • Google — Gemini models. Requires an API key.
  • Groq — Fast inference. Requires an API key.
  • Mistral — Open-weight models. Requires an API key.

Enter your API key if prompted, then click Continue.

Trust the SSL certificate authority

Prosponsive and its dependencies use only HTTPS with a self-signed certificate. You'll see a prompt to trust this certificate authority — click Trust Certificate and follow the instructions to allow Prosponsive to function. It will quickly restart after to use proper SSL authority verification.

Create your n8n Admin account

You'll be asked to create an n8n Admin account for the locally running n8n instance in your virtual environment. Fill in your details and click Save, then click the Refresh button in Prosponsive so it detects the new account.

Create an n8n API key and give it to Prosponsive

You'll then be asked to create an n8n API key and paste it into the Prosponsive UI, then click the Refresh button again. Prosponsive only communicates with n8n using its API; a critical, and very valuable, implementation detail because it means your Prosponsive agents never have access to credentials used by the tools you want them to use.
