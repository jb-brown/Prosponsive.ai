Prosponsive Install Guide

This guide covers installing Prosponsive and completing first-launch setup. Once you're up and running, continue to Prosponsive Basics to learn the interface.

1. Install Prosponsive

macOS

  1. Download the Prosponsive .dmg file from Prosponsive.ai.
  2. Open the .dmg and drag Prosponsive into your Applications folder.
  3. Open Prosponsive from Applications. macOS may ask you to confirm since the app was downloaded from the internet — click Open.

Windows

  1. Download the Prosponsive .exe installer from Prosponsive.ai.
  2. Run the installer and follow the prompts. Choose "Install for all users" if you want it available system-wide.
  3. Launch Prosponsive from the Start Menu.

Installation Overview

Prosponsive manages its own infrastructure. On first launch, it automatically starts the services it needs.

To install and run Prosponsive, you'll need:

  • A stable internet connection
  • Available disk space
  • Winget (Windows) or Homebrew (macOS)

What Prosponsive Installs

Prosponsive sets up three core components:

1. Virtualized Runtime Environment

Prosponsive runs its dependencies in a containerized environment:

  • Container engine
    Prosponsive prefers Podman and will download it if neither Podman nor Docker is present. If Docker Desktop is already installed, Prosponsive will use it and auto-start the daemon if it is stopped.
  • Database
    A PostgreSQL container is installed for persistent storage.
  • Workflow engine
    Prosponsive installs n8n, a source-available workflow engine licensed under the Sustainable Use License, used as a tool layer for your agents.

    n8n provides:

    • A visual workflow designer
    • Code-level extensibility
    • Secure credential storage
    • Thousands of templates
    • Full transparency into execution and data flow

Third-party software. Prosponsive automates the setup and integration of several independent software components including n8n, Podman or Docker Desktop, and PostgreSQL. Each of these is developed and maintained by its respective organization and is subject to its own licensing terms. It is the user's responsibility to review and comply with the applicable license agreements for each component.

2. Secure Local Networking

Your trust is a top priority. Even though all communication between Prosponsive, PostgreSQL, and n8n stays on your machine, Prosponsive enforces encrypted connections.

During setup:

  • A unique localhost SSL certificate is generated
  • On macOS, Prosponsive installs the certificate to your login keychain — you may be prompted for your password to authorize the trust
  • All certificate generation inputs are securely deleted afterward

3. LLM Provider and Model Selection

You can choose from popular cloud providers or run models locally.

Cloud providers (Anthropic, OpenAI, Google, Groq, Mistral, AWS Bedrock) deliver the most reliable experience. Local models via Ollama are also supported but may produce inconsistent results depending on model size and hardware.

Installation Time

Installation typically takes 5–30 minutes, depending on:

  • Whether container tooling (Podman/Docker) needs to be installed
  • Whether optional components need to be downloaded

2. First Launch

When you open Prosponsive for the first time, you'll see the Bamboo Journey — a guided timeline that walks you through setup one phase at a time. A zen garden background sets the scene, and a bamboo stalk grows alongside your progress as each phase completes. The footer shows how many of the seven steps are ready.

One phase card is active at a time. Complete it, and the next phase appears. Here's what to expect.

Phase 1: Consent

Prosponsive asks whether you'd like to opt in to anonymous analytics and instrumentation. Click Accept to opt in, or No thanks to decline. Either choice advances you to the next phase immediately.

Phase 2: Security

Prosponsive generates a unique localhost SSL certificate so all local communication is encrypted. On macOS, Prosponsive installs the certificate to your login keychain — you may be prompted for your password to authorize the trust. No app restart is required — trust is established before any HTTPS connections are made. A Refresh button is available to re-check if needed.

Phase 3: Container Runtime

Prosponsive needs a container engine to run its infrastructure. It prefers Podman and will offer to download it (~150 MB). A progress bar with a byte counter tracks the download.

Before the download begins, you must click Approve to acknowledge and authorize the installation. If Docker Desktop is already installed on your machine, Prosponsive uses it instead and auto-starts the Docker daemon if it is stopped.

Phase 4: Infrastructure

Prosponsive automatically pulls the n8n and PostgreSQL container images (~350 MB combined). A progress bar tracks the download. This phase is fully automatic — no user input is needed.

Phase 5: AI Provider

Choose the AI provider you want Prosponsive to use. Pick the one you have access to:

  • Anthropic — Claude models. Requires an API key. (Recommended)
  • OpenAI — GPT models. Requires an API key.
  • Google — Gemini models. Requires an API key.
  • Groq — Fast inference. Requires an API key.
  • Mistral — Open-weight models. Requires an API key.
  • AWS Bedrock — Claude and other models via AWS. Requires AWS credentials.
  • Ollama — Local models, no API key needed. Results vary by model and hardware.

Enter your credentials inline and continue.

Phase 6: Workflows

This phase has two manual sub-steps that connect Prosponsive to n8n:

  1. Create your n8n admin account. Click the Open Setup button — your browser opens to the n8n setup page. Create your account there, then return to the Prosponsive app and click Refresh so it detects the new account.
  2. Create an n8n API key. A password field and an Open API Settings button appear. Click the button to open n8n's API settings in your browser, copy the generated key, paste it into the field in Prosponsive, and click Save API Key.

Prosponsive only communicates with n8n through its API — a critical, and very valuable, implementation detail because it means your Prosponsive agents never have access to credentials used by the tools you want them to use.

Phase 7: Project Selection

Choose an existing project folder or create a new one. When you select a folder, Prosponsive initializes your project and the final phase completes.

Legal Acceptance

Alongside the phase cards, Prosponsive shows a brief section with two items: Privacy Policy and Terms of Service. Each row has a status and a Review and accept link that opens the document in a side panel. Read each one and click Accept to record your acceptance. Both must be accepted before the app can proceed.

This is a one-time step. Once accepted, the section does not appear again on subsequent launches.

Completion

When all seven phases are complete and both legal documents have been accepted, a short countdown appears and the app automatically advances to the main Prosponsive interface. You're ready to go.
