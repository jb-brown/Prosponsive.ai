Prosponsive Features

This guide covers what Prosponsive can do. It walks through each major capability so you can understand the full scope of the platform before diving into specific workflows. If you haven't used Prosponsive yet, start with the Install Guide and Basics.

1. AI-Powered Conversations

Prosponsive gives you a conversational interface to AI that works the way you think — not the way a single provider's API happens to work.

Multi-provider support

Prosponsive connects to multiple AI providers simultaneously. You're never locked in to one vendor. Supported providers include:

  • Ollama — Run models locally on your own hardware, completely offline
  • Anthropic — Claude models via direct API
  • OpenAI — GPT models via direct API
  • Google — Gemini models via direct API
  • Groq — Fast inference for open models
  • Mistral — Mistral models via direct API
  • AWS Bedrock — Enterprise-grade access to multiple model families through your AWS account

Model selection

Choose the right model for the job. Each provider offers different models with different strengths — some are faster, some are more capable, some are more cost-effective. You can switch models at any time from Settings without changing anything else about your setup.

Automatic failover

If your selected provider is unavailable, Prosponsive can fall back to another configured provider. This means your workflow doesn't stop because one API is having a bad day.

Agents and delegation

Conversations are managed by agents — AI assistants with specific roles, tools, and instructions. The default Prosponsive agent coordinates your workspace and delegates to specialist agents when needed. You can create as many custom agents as you want, each tailored to a specific domain.

For details on how agents work, see the Basics guide.

2. Tool System

Tools are what make Prosponsive more than a chatbot. They let agents take real actions — read files, call APIs, send notifications, query databases, and anything else you can wire up.

Powered by n8n

Every tool in Prosponsive is an n8n workflow. n8n is a visual workflow automation platform that runs locally alongside Prosponsive. This means:

  • Visual workflow designer — Build tools by connecting nodes in a drag-and-drop editor, not by writing code
  • 1000+ integrations — n8n has pre-built nodes for Slack, Gmail, Google Sheets, Notion, GitHub, Jira, databases, HTTP APIs, and hundreds more
  • Full control — You can inspect, modify, and debug every tool. Nothing is a black box

Credential isolation

This is a critical security feature. When an agent uses a tool, it never sees your credentials. Here's how it works:

  1. You store credentials in n8n's credential manager (encrypted at rest)
  2. When an agent calls a tool, it sends a request to the n8n workflow
  3. n8n executes the workflow using its stored credentials
  4. The agent only sees the result — never the API keys, passwords, or tokens

This means you can give agents access to powerful tools without ever exposing your secrets to the AI model.

Tool approval

Every tool call requires your approval before it executes. You see exactly what the agent wants to do, with what parameters, and why. You can also set up auto-approval rules for tools you trust, so routine actions don't require manual confirmation.

For details on building custom tools, see the Developer Guide.

3. Privacy and Security

Prosponsive is designed around a simple principle: your data stays on your machine.

Local-first architecture

Prosponsive runs entirely on your computer. There is no Prosponsive cloud service, no Prosponsive account, no telemetry, and no data collection. The application, the database, the workflow engine, and your conversations all live on your machine.

What leaves your machine

The only data that leaves your computer is what you explicitly send to an AI provider when you have a conversation. If you use Ollama, nothing leaves your machine at all — the AI model runs locally too.

Encrypted connections

All local services communicate over encrypted connections using SSL certificates generated during setup. This includes the connection between Prosponsive and n8n, and between n8n and the local database. Even though everything is on your machine, connections are encrypted as if they were crossing the internet.

No cloud dependency

Prosponsive does not require an internet connection to function (assuming you use a local AI provider like Ollama). There is no license server, no activation check, and no feature gating tied to a remote service. If your internet goes down, Prosponsive keeps working.

Encrypted storage

Sensitive data — API keys, provider credentials, and secure settings — is encrypted at rest using a machine-specific encryption key. Your credentials are never stored in plain text.

4. Provider Agnostic

You are not locked in to any AI provider. Prosponsive treats providers as interchangeable backends.

Switch anytime

Changing your AI provider is a single setting change. Your conversations, agents, tools, and workflows are completely independent of which provider you use. Switch from OpenAI to Anthropic to Ollama and back — nothing else changes.

5. Extensibility

Prosponsive is designed to be extended, not just configured.

Custom agents

Create agents tailored to your specific needs. An agent definition includes:

  • System prompt — The agent's personality, expertise, and instructions
  • Allowed tools — Which n8n workflows the agent can invoke
  • Delegation rules — Which other agents it can hand off to
  • Channel sharing — Which conversations the agent participates in

Agents are defined in markdown with YAML frontmatter — readable, version-controllable, and easy to duplicate.

Custom n8n workflows

Build any tool you can imagine using n8n's visual workflow designer. Common patterns include:

  • Connecting to external APIs (CRMs, project management, communication tools)
  • Querying and updating databases
  • Processing files and documents
  • Sending notifications (Slack, email, SMS)
  • Orchestrating multi-step business processes

Thousands of integrations

Through n8n, Prosponsive can connect to over a thousand external services out of the box. If a service has an API, you can build a tool for it — often without writing a single line of code.

For a hands-on guide to building tools, see the Developer Guide.

7. Scheduled Prompts

Scheduled prompts let you automate recurring AI tasks so they run on a regular cadence without manual intervention.

What they do

A scheduled prompt sends a message to a specific agent at a set time — daily, weekly, or on whatever schedule you define. The agent processes the prompt using its tools and posts the result to the designated channel, just as if you had typed the message yourself.

Use cases

  • Morning briefings — Have an agent compile a daily summary from your data sources every morning
  • Periodic reports — Generate weekly metrics, status updates, or digests automatically
  • Data monitoring — Check for changes in external systems and surface anything that needs attention
  • Recurring maintenance — Run cleanup, archival, or organization tasks on a schedule

How to set them up

Open Settings and find the Scheduled Prompts section. Each scheduled prompt has:

  • Prompt text — The message to send
  • Agent — Which agent should handle it
  • Channel — Where the result appears
  • Schedule — When and how often it runs (cron-style scheduling)

Scheduled prompts run locally on your machine — they don't depend on any cloud service. If your machine is off at the scheduled time, the prompt will run the next time Prosponsive starts.
