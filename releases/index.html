Release Notes

What's new in Prosponsive

v1.0.51 — May 13, 2026

Account and Subscriptions

  • Free and paid tiers — sign in to unlock higher usage limits, or continue anonymously with the starter tier
  • Usage at a glance — your current usage, plan tier, and weekly reset countdown appear in the account flyout
  • Seamless checkout — subscribing and managing your subscription open directly in your browser; the app refreshes your entitlement immediately after checkout
  • Promo codes — promo codes are now accepted at checkout
  • Automatic usage sync — usage counts sync when you reconnect to the internet, resume from sleep, or bring the app to the foreground

Terms of Service and Privacy Policy

  • Prosponsive now includes a Terms of Service, EULA, and Privacy Policy, presented on first launch
  • Anonymous users can accept before signing in, and their acceptance carries over when they create an account

Multi-Agent Orchestration

  • Coordinated agent chains — AI chains can now coordinate multiple specialized agents in a single response; maximum chain depth is configurable in Settings
  • Configurable limits — the maximum number of tool steps per response and the AI inference timeout are now configurable in Settings

Tool Approval and Auto-Approval Rules

  • Confidence badges — tool approval cards show the AI model's self-rated confidence as a color-coded badge
  • Confidence thresholds — auto-approval rules support an optional confidence threshold: auto-approve only when confidence meets your threshold, or auto-deny when it falls below
  • Approvals survive restarts — pending tool approvals are preserved across app restarts
  • Tool categories are now labeled "Core tools" and "Custom tools"

Thread Summaries

  • Automatic summaries — collapsed threads show a conversation summary; if the model skips generating one, the app retries in the background
  • Persistent collapse state — thread collapse/expand state is saved across sessions
  • The thread summary prompt is customizable in Settings

Windows

  • Code-signed builds — Windows builds are now code-signed via Azure Trusted Signing, eliminating the SmartScreen warning on launch

Reliability

  • Conversation messages that fail to save due to a transient database error are now retried automatically
  • Custom tool discovery retries automatically when the initial cache is empty after a failed startup
  • Fixed several edge cases in session restore, token refresh, and sign-in state after restart
  • Fixed completed tool calls occasionally re-executing on re-entry into a thread
  • Default Ollama model is now llama3.1:8b
  • The local API server now requires authentication, so only Prosponsive's own services can reach it

Security

  • Electron renderer runs in a sandboxed process with a Content Security Policy
  • All TLS connections enforce TLS 1.2 minimum with FIPS-approved ciphers
  • Container bind mounts are read-only where possible; log files are owner-readable only
  • Auto-update downloads are verified with SHA-512 checksums and publisher signature before installation

Security

  • Continued security enhancements across the platform

More Reliable Installation

  • Smoother setup experience — Prosponsive guides you through each step more reliably, confirming services are ready before moving forward
  • Automatic recovery — if something gets out of sync during setup, Prosponsive detects and repairs it automatically

Smarter Daily Use

  • Dates in your timezone and language — timestamps are formatted for your locale, not displayed as raw UTC

Better Visibility

  • Improved install analytics — helps us identify and fix setup issues faster for new users

Platform

  • Windows code signing — Windows builds now provide a verified installation experience
