What's new in Prosponsive

v1.0.50 — April 17, 2026

Security

  • Continued security enhancements across the platform

More Reliable Installation

  • Smoother setup experience — Prosponsive guides you through each step more reliably, confirming services are ready before moving forward
  • Automatic recovery — if something gets out of sync during setup, Prosponsive detects and repairs it automatically

Smarter Daily Use

  • Cleaner tool names — tools show simple names like "Archive Channel" instead of cluttered internal prefixes
  • Dates in your timezone and language — timestamps are formatted for your locale, not displayed as raw UTC
  • Automatic provider failover — if your AI provider goes down or you hit a rate limit, Prosponsive switches to your next provider and keeps working

Better Visibility

  • Improved install analytics — helps us identify and fix setup issues faster for new users

Platform

  • Windows code signing — Windows builds now provide a verified installation experience

v1.0.49 — April 15, 2026

  • Completely redesigned install and onboarding experience — a cleaner, faster path to getting started with Prosponsive
  • SSL certificate trust now works seamlessly — no more browser security warnings or password prompts
  • Inline replies in conversations are now perfectly positioned — no overlapping, shifting, or clipping
  • Fixed a macOS Dock bug that could show duplicate Prosponsive icons
  • Guest agent delegation is now more reliable — thread replies work correctly in shared channels
  • Switched to PostHog analytics for better insight into how we can improve the app
  • Chat state is more robust — eliminated optimistic update glitches and cache drift issues
  • AI provider connections now require your explicit approval before activating, giving you full control

v1.0.47 — April 9, 2026

  • AI Provider configuration fixes
  • Your custom n8n workflows are now preserved when Prosponsive updates — no more losing your changes on restart

  • Fixed first-run provider setup so you can proceed after connecting your AI provider

  • Connect to the AI that works best for you — Ollama, OpenAI, Anthropic, Google, AWS Bedrock, Groq, and Mistral all supported out of the box
